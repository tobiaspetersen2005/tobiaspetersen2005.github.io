# Documents Directory

Place your official PDF documents in this folder so visitors and recruiters can view and download them directly from your personal website:

1. `resume.pdf` — Curriculum Vitae (Resume)
2. `graduation-certificate.pdf` — ZBC Graduation Certificate & Grades Transcript
3. `recommendation.pdf` — School Recommendation Letter

Once you copy your PDF files into this `documents/` directory with the exact names above, the website's preview modals and download buttons will automatically link to them!
